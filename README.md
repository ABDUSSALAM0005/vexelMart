A comprehensive full-stack MERN e-commerce application featuring a dynamic customer storefront, real-time shopping cart state management, and a secure, role-based admin dashboard.

✨ Key Features
🛍️ Dynamic Shopping Cart: Complex React state management handles real-time price calculations, item quantity updates, and seamless checkout flows without unnecessary re-renders.

🔐 Role-Based Admin Dashboard: Secure route protection for admins to manage inventory, update product listings, and oversee operations.

📱 Fully Responsive UI: A mobile-first, highly intuitive user interface styled with Tailwind CSS to optimize the buyer's journey from discovery to purchase.

⚡ RESTful API Integration: Smooth and secure communication between the React frontend and the Express/Node.js backend.

🛠️ Tech Stack
Frontend: React.js, Tailwind CSS, Context API (State Management)

Backend: Node.js, Express.js

Database: MongoDB

Deployment: [e.g., Vercel for Frontend, Render for Backend]
